# Methodology

## Project Design

The project maps directly to a Private Bank Investment Professional Associate support workflow:

1. Review client profiles and mandate constraints
2. Review current holdings and asset-class allocation
3. Calculate portfolio-level expected return, income yield, volatility, and unrealized gain/loss
4. Run scenario-based what-if analysis across different market environments
5. Reconcile paper blotter to trade blotter
6. Identify trade exceptions requiring review or correction
7. Track alternatives subscription documentation
8. Review fee schedules and billing exceptions
9. Summarize outputs in an executive-ready workbook and presentation

## Data Design

All data is synthetic. The dataset intentionally includes both clean and exception-driven examples to demonstrate:
- analytical thinking
- exception identification
- follow-through
- risk awareness
- documentation discipline
- client service orientation

## Limitations

This project does not prove direct brokerage-trade execution experience. It demonstrates transferable skills: reconciliation, trade-control logic, exception monitoring, scenario analysis, account review support, and executive communication.

## Suggested Interview Framing

Use the project as evidence that you understand the workflow and can learn proprietary private-bank systems quickly. Do not describe it as client work or securities experience.
